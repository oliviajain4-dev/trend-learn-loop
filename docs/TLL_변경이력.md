# TLL 변경·결정 이력 (내가 고친 것·왜)

> "실수/수정이 어디 저장되냐"에 대한 답. **에이전트의 KB(`data/memory`)는 '기술 지식'(교과서·교훈)용**이지
> 내 코드 수정용이 아니다. **내 설계 결정·버그·수정은 여기(docs) + 코드 + 테스트 + git 에 남는다.**
> 규칙 상세는 `TLL_티어규칙.md`, 자기점검은 `TLL_기준점검.md`.

## 티어·점수 설계
- **8동물 + 정량 규칙**: 호랑이·코끼리·거북이·치타·새싹·공룡·하루살이·하이에나 = 채택/주목/모멘텀/나이/재등장의 명시 임계값.
- **RAG=코끼리 결함 교정**: '정착'을 스냅샷+불량 나이(arXiv 최초논문일)로 판정하던 것 → **내구성 = 신뢰나이(GitHub 생일 ≥4년) 또는 (측정된 평탄+재등장≥3)**. arXiv 나이는 안 씀. 단일소스는 확정 상위 티어 금지.
- **채택 = 참여 중심**: 별(★)은 약한 지표라 0.1로 강등, 포크·이슈·PR 중심. **손앵커 → 포화함수** 정규화(min-max 아님).
- **합의 보정**: arxiv_recent는 arxiv_total과 동일소스라 합의에서 제외.

## 신호·소스
- **기법 발견기**(`signals/terms.py`): HN·arXiv 제목에서 약어+헤드명사 구 추출 → 하네스·RAG 같은 repo 없는 개념 자동 등록.
- **소스 다양화**: Reddit·공식(벤더 RSS)·YouTube 추가. **소스 역할 모델** — 공식=발견/원천(자기홍보라 독립투표 제외), 커뮤니티=유기적(1.0), 유튜브=대두(0.8), 논문=후행·고품질.
- **자랑 vs 허세** = 텍스트가 아니라 '남이 독립적으로 받아주냐'. 공식만이면 허세→새싹/하루살이.
- **미측정 개념 채택 구제**(`resolve_adoption`): 'Node.js처럼 언급만 되고 채택 0'인 개념을 **이름으로 GitHub 조회**해 실제 별·포크·나이를 붙인다. (엉뚱 저장소 방지: 이름 매칭 필수)

## 버그 수정 (라이브에서 터진 것)
- **대시보드 자동수집 크래시**: `run_forever`가 `only_new`를 이중 전달 → 매 사이클 실패. `_start_agent`에서 중복 제거 + `run_forever` 방어.
- **레지스트리 90개 소실(치명)**: 손상 파일을 '빈 레지스트리'로 로드→그대로 저장하며 개념이 대량 증발. → **로드는 부분 살바지→`.bak` 복구 순(빈 걸로 안 덮음), 저장은 직전본을 `.bak`로.** 신호·교과서에서 47개 복원.
