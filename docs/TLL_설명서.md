# TLL 설명서 — 스스로 찾고·읽고·집필하고 랭킹하는 자율 에이전트

> **한 줄 정체:** 최신 IT/AI 기술을 에이전트가 **스스로 발견 → 공식문서 읽기 → 한국어 교과서 집필 → 충실도 검증 → 중요도 랭킹**까지 하는 30분 주기 자율 루프.
> **철학:** *불완전한 LLM을 **근거·검증·겸손·추적**으로 감싼다.* 판단은 최소한만 LLM에 맡기고, 검증·랭킹·환율은 결정론(코드)으로.

---

## 0. 왜 만드나 (Why)

최신 기술이 하루에도 수십 개씩 쏟아진다. 사람이 다 못 따라가고, "무엇이 진짜 중요한지"도 흐릿하다. TLL은 이 문제를 이렇게 푼다:

1. **자율 발견** — 사람이 주제를 넣지 않는다. 에이전트가 스스로 트렌드를 훑어 고른다.
2. **근거 집필** — 공식 원문만 읽고 한국어 교과서로 풀어 쓴다(지어내지 않음).
3. **충실도 검증** — 쓴 문장이 원문에 실제로 있는지 결정론으로 대조해 "충실도 %"를 매긴다.
4. **중요도 랭킹** — 반짝 유행과 진짜 중요한 기술을 **측정된 신호**로 구분한다(감이 아니라).

## 1. 우리가 쓴 기술 / 개념 — 정직하게 (뭘 쓰고 뭘 안 썼나)

| 개념 | 썼나 | 어디서 · 어떻게 | 왜 |
|---|---|---|---|
| **LLM** (Gemini / Anthropic) | ✅ | `shared/llm` 프로바이더. Triage·Reader·Author·개념추출이 호출 | 판단·집필의 두뇌 |
| **ReAct** (Reason + Act) | ✅ | `Reader`의 *충분? / 더 찾자?* 판단 → `Loop`가 그 결정으로 다음 행동 | "관찰→판단→행동" 루프의 핵심 |
| **RAG** (검색 기반 생성) | ✅ *스타일* | `Scout·Tracker`가 원문 검색·수집 → `Author`가 **원문에만 근거**로 집필 → `Fact-Check`가 원문 대조 | 환각 억제. 단 **벡터DB가 아니라** "문서 검색 + 근거 집필" 형태 |
| **에이전트 하네스**(Harness) | ✅ *자체 구축* | `Loop`(스케줄·안전장치) + 의존성 주입 + 결정론 검증이 곧 하네스 | 프레임워크 대신 직접 = 투명·제어·재현 |
| **Reflexion** (교훈 축적) | ✅ | `Memory`의 lessons — 실패("더 찾자") 사유를 기록 | 다음 사이클이 배움 |
| **CoALA** (기억 구조) | ✅ | `Memory` = 의미기억(개념 KB) + 일화기억(lessons) | 대조·유추 근거 축적 |
| **STORM / Co-STORM** | ◐ 부분 | 근거 기반 글 생성 아이디어 차용. mind-map은 **동물 티어 랭킹**으로 대체 | 우리 목적(교과서+랭킹)에 맞게 변형 |
| **LangChain** | ❌ **안 씀** | — | 오케스트레이션을 **직접** 구현(투명·결정론·검증 위해) |
| **LangGraph** | ❌ **안 씀** | — | 상동. 우리 `Loop`가 그 그래프 역할을 결정론으로 수행 |
| **Vector DB / 임베딩** | ❌ 아직 | `Memory` 대조는 현재 **어휘 겹침**(임베딩 아님) | 다음 고도화 항목(정직한 한계) |

> **핵심 정리:** LLM · ReAct · RAG(스타일) · 자체 하네스 · Reflexion · CoALA = **씀**.
> **LangChain / LangGraph = 안 씀** — 채용 과제의 목적이 "직접 만들어 이해·제어·검증"이라, 프레임워크에 감추지 않고 뼈대를 손으로 짰다. (Anthropic「Building Effective Agents」도 프레임워크 남용을 경고한다.)

## 2. 전체 구조 (아키텍처)

그림: `docs/tll_architecture_v4.svg`

두 줄기가 하나의 대시보드로 합쳐진다.

- **교과서 줄기 (①~⑦):** 소스 → Scout(정찰) → Triage(선별) → Tracker(추적) → Reader(독해) → Author(집필) → Fact-Check(검증)
- **랭킹 줄기 (⑧~⑪):** (후보마다) 개념화 → 신호 로그(주목·채택) → 점수 → 동물 티어
- **⑫ 대시보드:** 둘을 합쳐 "중요한 기술부터, 클릭하면 한국어 교과서".
- **곁:** `Loop`(30분 반복·안전장치), `Cost`(토큰·요금), `FX`(환율 자동).

**색으로 구분한 두 두뇌:**

- 🟣 **에이전트(LLM 판단):** Triage · Reader · Author · 개념추출 — *모델이 다음을 정한다*
- 🟢 **결정론(코드·검증):** Scout · Tracker · Fact-Check · 점수·랭킹 — *같은 입력 → 같은 결과*
- 🔵 기억·저장, 🟡 랭킹 결과·화면.

원칙: **판단은 좁게 LLM에, 검증·랭킹은 결정론에.** LLM이 틀려도 결정론 검증이 받쳐준다.

## 3. 각 조각 딥 설명 (무엇을 · 왜 · 어떻게)

각 항목: **역할 → 왜 필요 → 에이전트냐 결정론이냐 → 입력→출력 → 파일 → 한계**.

### ① 소스 & 등급 (1급/2급/3급)
- **역할:** 관측 대상. HN·GeekNews(현장 신호), 링크 타고 만나는 공식문서·논문·뉴스.
- **왜:** "어디서 보느냐"가 신호의 질을 절반 정한다. 그래서 **원천 근접도**로 등급을 매긴다 — 1급 공식/논문(근거), 2급 뉴스(정리), 3급 커뮤니티(빠른 온도).
- **정직한 주의:** 등급 ≠ 진실. 공식 발표도 자랑·과장이 섞인다 → "주장"으로 다룬다.

### ② Scout · 정찰 — 🟢 결정론
- **역할:** 실시간 소스를 훑어 **트렌드 후보** 목록을 만든다. 이미 본 것은 걸러 새 것만(신규성).
- **왜 결정론:** 발견·중복제거는 규칙으로 재현 가능해야 한다(LLM 낭비 없이).
- **입력→출력:** 소스 → `TrendCandidate[]` (제목·URL·등급·HN점수).
- **파일:** `src/tll/scout/`, 상태 `data/memory/seen.json`.
- **한계:** 지금은 HN·GeekNews만 능동 폴링(arXiv·유튜브·SNS는 링크로만).

### ③ Triage · 선별 — 🟣 에이전트
- **역할:** 후보 중 "**교과서로 쓸 감**"과 "소음"을 LLM이 가른다. 카테고리도 붙인다.
- **왜 에이전트:** "이게 배울 가치가 있나?"는 맥락 판단 → LLM이 낫다.
- **입력→출력:** 후보 → 선별된 상위 N + 카테고리.
- **파일:** `src/tll/triage/`.
- **한계(구멍):** 이 판단엔 **검증이 없다** — "중요"를 환각해도 잡는 장치가 아직 없음.

### ④ Tracker · 추적 — 🟢 결정론 (+링크 선택)
- **역할:** 후보의 **공식 문서 본문**을 실제로 가져오고(robots·rate-limit 준수), 출처 등급·성격을 매긴다.
- **왜:** 집필은 반드시 **원문**에 근거해야 하므로, 진짜 본문을 확보한다.
- **입력→출력:** 후보 → `TrackedDoc`(body_text·grade·nature·status).
- **파일:** `src/tll/tracker/`.
- **한계:** non-HTML·페이월·JS 렌더 페이지는 제한.

### ⑤ Reader · 독해 — 🟣 에이전트 (ReAct의 심장)
- **역할:** 확보한 본문이 **교과서 쓰기에 충분한지** 판단. 충분→집필로, 부족→"더 찾자".
- **왜 에이전트:** 충분/불충분은 내용 이해가 필요 → LLM. 이 결정이 루프의 다음 행동을 바꾼다(ReAct).
- **입력→출력:** 본문 → `sufficient` / `collect_more`(+사유).
- **파일:** `src/tll/reader/`.
- **한계:** 현재 "더 찾자"는 같은 주제 재수집이 아니라 **다음 후보로 이동**(+교훈 기록)으로 처리.

### ⑥ Author · 집필 — 🟣 에이전트 ★
- **역할:** 충분 판정된 원문으로 **쉽고 자연스러운 한국어 교과서**를 쓴다. 각 사실 문장에 `[S1]`(검증표시), 기존 기술과의 **대조·유추** 포함.
- **왜:** 목적물. 원문 밖 내용은 (일반지식)으로 표시해 나중에 미확인 처리.
- **입력→출력:** 원문 + Memory 회상(대조 힌트) → `Textbook`(6섹션·판단·미확인).
- **파일:** `src/tll/author/`.
- **한계:** 섹션 품질은 원문 품질에 좌우(편차 있음).

### ⑦ Fact-Check · 검증 — 🟢 결정론 ★
- **역할:** 쓴 문장을 **실제 원문 문자열과 대조**. 인용 누락·유령 인용·수치 미근거를 잡아 **충실도 %**를 계산.
- **왜 결정론:** LLM에게 "맞아?"를 물으면 자기 환각을 승인할 수 있다 → 코드로 대조해야 신뢰.
- **입력→출력:** `Textbook` → 충실도%·미확인 목록·상태(검증됨/초안).
- **파일:** `src/tll/factcheck/`.
- **한계:** "원문에 있나"(충실도)만 본다. **원문 자체의 진위·해석 오류는 못 본다**(정직한 경계).

### ★ Memory · KB — 🔵 기억
- **역할:** 배운 **개념**을 축적(의미기억)하고, 실패 **교훈**을 쌓는다(일화기억=Reflexion). Author에 "대조·유추 근거"를 준다.
- **파일:** `src/tll/memory/`, `data/memory/concepts.json`·`lessons.json`.
- **한계:** 회상이 **어휘 겹침**(임베딩 아님) → 대조 품질에 상한.

### ⑧ Ingest · 개념화 — 🟣 추출(LLM) + 🟢 레지스트리(결정론)
- **역할:** 후보 글이 "무슨 **기술 개념**"인지 이름을 뽑고(LLM), 그 이름을 기존 개념에 **결정론으로 중복해소**(별칭 매칭). 없으면 신규를 `provisional`로.
- **왜:** 랭킹의 단위를 "글"이 아니라 "**기술 개념**"으로 만든다. LLM 추출 실수의 영향은 결정론 dedup이 좁힌다.
- **파일:** `src/tll/concepts/`(extract·registry), `data/memory/concepts_registry.json`.
- **한계(구멍):** 추출 품질 편차 — 가끔 엉뚱한 이름(예: "Turing Machine")을 뽑음.

### ⑨ 신호 로그 — 🔵 저장
- **역할:** 개념마다 **주목**(HN 점수·댓글=버즈)과 **채택**(GitHub 스타·포크·이슈)을 **시간열**로 append.
- **왜:** 랭킹·재라벨은 과거 신호가 쌓여야 가능. 이게 "돌릴수록 똑똑해지는" 재료.
- **파일:** `src/tll/signals/`, `data/memory/signals.jsonl`.
- **한계:** 지금은 GitHub만·누적 스냅샷 가정. 다운로드·SNS·유튜브는 아직.

### ⑩ 점수 (주목 vs 채택) — 🟢 결정론
- **역할:** 신호에서 두 시계열을 계산. **주목**=버즈 지수감쇠(빨리 식음), **채택**=최근 성장 모멘텀(천천히 쌓임). + 다중신호 합의, 가짜 별 필터.
- **왜:** 시끄러운 것 ≠ 중요한 것. 둘을 **절대 안 섞고**, 격차로 거품/진짜를 가른다.
- **파일:** `src/tll/rank/score.py`.
- **한계:** 임계값 미튜닝, 개념 간 상대 정규화(백분위)는 아직.

### ⑪ 동물 티어 — 🟡 표시층
- **역할:** 위 숫자를 **배지**로 번역. 🐯호랑이(중요+대두)·🐘코끼리(정착)·🐆치타(급부상 미검증)·🦕공룡(지는 중)·🐺하이에나(파생·가짜)·🦟하루살이(반짝).
- **왜:** 사람이 한눈에 읽게. **로직이 아니라 표시** — 이름 바꿔도 계산은 안 건드림(튜너블 config).
- **파일:** `src/tll/rank/tier.py`·`board.py`.

### ⑫ 대시보드 — 🟡 화면 (Streamlit)
- **역할:** 기술을 **티어순**으로(중요한 것 위로), 펼치면 한국어 교과서·원문·충실도. 관리>비용(원화 자동환율).
- **파일:** `src/tll/manage/app.py`.

### 곁: Loop · Cost · FX
- **Loop**(`src/tll/loop/`): 위 조각을 감싸 **30분마다** 한 사이클. 안전장치(발행 예산·시도 상한·무진전 가드). ← 이게 "하네스".
- **Cost**(`src/tll/cost/`): 호출마다 **실제 토큰**을 로깅 → 요금 계산.
- **FX**(`src/tll/cost/fx.py`): USD→KRW **실시간 자동 갱신**(12h 캐시, 실패 시 폴백).

## 4. 랭킹 방법론 — 왜 이렇게 (논문 근거)

**핵심:** 주목(attention)과 채택(adoption)을 **한 점수로 절대 안 섞는다.** 둘을 독립 시계열로 재고, 격차가 "거품이냐 진짜냐"를 말한다.

- **주목은 빨리 식는다** → 지수감쇠(반감기). (Pfeffer 2023, ICWSM: 트윗 반감기 ≈80분)
- **채택은 천천히 쌓인다** → 최근 성장 모멘텀. (Kazemian 2025: 스타→포크 선행)
- **단일 지표는 못 믿는다** → 상승 신호 ≥2개 합의해야 "채택". (Koch 2024 NDSS; Zerouali 2019: 지표 간 상관 0.14~0.47)
- **가짜 별 필터** — 스타↑인데 이슈·PR·포크 정체면 감점. (He 2026 ICSE: 2024년 인기 저장소 최대 16.7%가 가짜 별, AI가 최대 피해)
- **하이프사이클 강요 금지** — 실증적으로 약함(Dedehayir 2016). 대신 두 시계열의 다이버전스로 판단.
- **잠정 라벨 + 재라벨** — 조기 신호는 틀리기 쉬움(WISDOM 2024, Cauthen 2022) → 2주기+ 재등장해야 승격.

## 5. 신뢰 설계 (Trust) — "불완전한 LLM을 감싼다"

네 겹으로 감싼다: **근거**(원문만) · **검증**(결정론 대조) · **겸손**(잠정·미확인 표시) · **추적**([S1]·원문 링크로 감사 가능).

**정직한 구멍 3개 (아직 안 막음):**
1. **판단 무검증** — Triage·Reader의 LLM 판단엔 검증 장치가 없다.
2. **원문 진위 무검증** — 1급 공식이라도 마케팅·과장일 수 있음(충실도는 "원문에 있나"만 봄).
3. **개념 추출 오류** — 이름 오추출 가능(결정론 dedup이 영향을 좁힐 뿐).

| `data/memory/concepts.json`·`lessons.json` | Memory KB·교훈 |
| `data/textbooks/*.json` | 교과서(+`concept_cid` 꼬리표) |
| `data/cost/usage.jsonl` · `fx_cache.json` | 토큰 사용량 · 환율 캐시 |

저장은 **원자적**(tmp→replace)이고 로드는 **방탄**(손상 파일이면 빈 걸로 시작, 크래시 없음).

## 8. 실행법 (명령어)

```bash
# 0) (선택) 모델·환율 환경변수
#    .env 또는 셸에: TLL_PROVIDER=gemini|anthropic  ·  TLL_USD_KRW=1510 (수동 고정 시)

# 1) 화면 열기 (대시보드) — 이게 메인
streamlit run src/tll/manage/app.py
#    → 왼쪽 메뉴: 📚 기술 / ⚙️ 관리(개요·비용)

# 2) 에이전트 한 사이클 (교과서·신호 쌓기)
python -m tll.loop.loop
#    모델 바꿔서:  python -m tll.loop.loop --provider anthropic

# 3) 30분마다 자동 반복 (Ctrl-C 로 중단)
python -m tll.loop.loop --watch

# 4) 테스트 (전부 통과 확인)
for t in tests/test_*.py; do python "$t"; done
```

> 처음엔 `python -m tll.loop.loop` 를 **한두 번 돌린 뒤** 대시보드를 열면 기술이 채워진다.
> (며칠 `--watch` 로 돌려야 채택 데이터가 쌓여 🐯 호랑이가 뜬다.)
