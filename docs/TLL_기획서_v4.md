# TLL 기획서 v4 — 관측망 + 중요도 랭킹 (근거 기반)

> v3(자율 발견·충실도) 위에, **"무엇이 진짜 중요한가"를 감이 아니라 측정으로 판단**하는 랭킹 체계를 얹는다.
> 방향은 20+편의 문헌 근거로 세웠다(근거 목록 §9). 코드보다 문서에 먼저 못 박는다.

## 0. v3 → v4, 무엇이 바뀌나
- **단위**: "글 한 편(HN 포스트)" → **"기술 개념 하나"**(LangChain·RAG·MCP…). 포스트는 개념을 갱신하는 *신호*일 뿐.
- **랭킹**: LLM 감("중요해") → **측정된 신호**(주목·채택·재등장).
- **핵심 발상**: **주목(attention)과 채택(adoption)을 절대 한 점수로 섞지 않는다.** 둘을 독립 시계열로 재고, 그 **격차(gap)**가 거품/진짜를 가른다.

## 1. 원칙 한 줄
> 시끄러운 것(주목) ≠ 중요한 것(채택).
> **재고 · 여러 개로 재서 맞장구칠 때만 믿고 · 틀릴 수 있으니 잠정이라 말하고 · 나중에 다시 채점한다.**

이유: 감은 틀린다. (설계 중 실제로 LLM이 "하네스 엔지니어링"의 성숙도를 오판함 → 측정 우선의 산 증거.)

## 2. 관측망 (Observation Network)
어디서 보느냐가 신호의 질을 절반 정한다. 관측망은 **두 축 + 두 보조 태그**로 정리한다.

- 축1 **등급(원천 근접도)**: 1급 원천 / 2급 중개 / 3급 현장
- 축2 **성격(신호 종류)**: 발표·학술·SNS·뉴스·커뮤니티·코드·교육·실사용
- 보조 **하이프 위험도**: 장르 기반(보도자료·마케팅=고, 문서·체인지로그·논문 방법=저)
- 보조 **실측 선행성**: "어느 소스가 먼저 뜨나"는 가정하지 않고 개념별로 *측정*한다

| 층 | 소스 | 등급 | 주는 신호 | 주의 |
|---|---|---|---|---|
| 원천 | 논문(arXiv·학회) | 1급 | 엄밀 근거·깊이 | 느림·체리피킹 |
| 원천 | 공식 문서·릴리스노트 | 1급 | 정확히 무엇인지 | 최신·정확 |
| 원천 | 공식 발표·블로그 | 1급 | 무엇·왜·빠름 | ⚠️ 자랑·허세 |
| 원천 | 공식 SNS(X·LinkedIn·인스타·공식 유튜브) | 1급 | 가장 빠른 속보 | ⚠️ 허세 최대 |
| 중개 | IT 뉴스·전문매체 | 2급 | 맥락·정리 | 2차 해석 오류 |
| 중개 | 애널리스트 리포트 | 2급 | 시장·채택 관점 | 느림·유료 |
| 현장 | 커뮤니티(HN·Reddit·GeekNews) | 3급 | 초기 온도·모멘텀 | 노이즈·유행 |
| 현장 | 코드 생태계(GitHub·npm·PyPI) | 3급 | 실채택 대리·깊이 | ⚠️ 스타=허영 |
| 현장 | 유튜브·블로그 크리에이터 | 3급 | 대중화·교육 | ⚠️ 과장·지연 |
| 현장 | Q&A·실사용(StackOverflow·Discord) | 3급 | 진짜 쓰는 신호 | 커버리지 편차 |

**폐기**: "층 = 고정 신뢰가중". 근거: 공식 원천도 33~72% 과장(Sumner 2014; Batalo 2026), 어느 소스가 선행하는지는 주제마다 뒤집힘(Šķestere 2022).

### 확산 경로
발표(원천) → 현장·SNS 즉시 반응 → 중개(뉴스) 정리 → 크리에이터(유튜브) 해설·소비 → 코드 채택·논문 인용.
**호랑이는 이 경로를 빠르고 끝까지 통과한다. 하루살이는 1차 반응에서 끊긴다.**

## 3. 두 시계열 — 주목 vs 채택
개념마다 **두 개의 시계열**을 유지한다.

- **주목(버즈형)**: HN·Reddit·뉴스·유튜브·SNS 언급/점수. **시간~일 단위로 빨리 식는다** → 지수감쇠(반감기 수 시간~수일).
  근거: 트윗 노출 반감기 ≈80분, 24h면 95% 사멸(Pfeffer 2023); 바이럴 절반은 1주 내 소멸(Sangiorgio 2025).
- **채택(축적형)**: GitHub 스타/포크/이슈/PR/의존성, 다운로드, 논문 인용. **월 단위 누적** → 절대감쇠 대신 모멘텀(최근 증가율 ÷ 기준 증가율, EWMA).
  근거: 스타→포크 선행, 초기 2주 기울기가 5년 뒤를 예측(Kazemian 2025).

**결합**: 그냥 더하면 버즈가 압도한다 → **별도 축으로 유지하고 스코어카드로 결합**(단순 합산 금지).

### 다중신호 합의 + 가짜 필터
- **≥2개 독립 신호가 함께 오를 때만 "채택"으로 승격.** 하나만 튀면 "주목"에만 반영.
  근거: 단일 지표 상호상관 0.14~0.47, npm 9개 지표 상위 겹침 5.1%(Koch 2024; Zerouali 2019).
- **조작저항 가중**: 스타 낮게, 의존성·다운로드·실배포 높게.
- **가짜 필터**: 스타 급증인데 이슈·PR·포크가 정체면 감점.
  근거: 2024년 인기 저장소 최대 16.7%가 가짜 별, **AI가 최대 피해 카테고리**(He 2026, ICSE). ← 우리 도메인이라 필수.

## 4. 동물 티어 = 주목 × 채택 + 모멘텀
곡선(하이프사이클)을 억지로 씌우지 않는다(실증적으로 약함: Dedehayir 2016). 티어는 **좌표의 결과**다.

| 티어 | 조건 | 행동 |
|---|---|---|
| 🐯 호랑이 | 채택↑ + 주목↑ + 재등장 | 지금 배워라 |
| 🐘 코끼리 | 채택 높고 주목 낮음(정착) | 필수·안 급함 |
| 🐆 치타 | 주목 급등·채택 미검증 | 잠정·지켜봐 |
| 🦕 공룡 | 채택↓ | 참고만 |
| 🦟 하루살이 | 주목 스파이크·채택 0·재등장 없음 | 무시 |
| 🐺 하이에나 | 주목 빌려옴·채택 낮음·가짜 플래그 | 걸러 |

### 잠정 라벨 + 재라벨 루프
- 갓 뜬 것은 **"잠정(provisional)" + 넓은 불확실성**으로 표시. **2주기 이상 재등장**해야 지속 티어로 승격.
- 6개월~2년 뒤 시스템이 스스로 재라벨 → 과거 판단의 적중을 채점.
  근거: 조기 신호가 지속으로 자란 사례 0/18(WISDOM 2024), 초기단계 오분류율 3배(Cauthen 2022), **장기 종단 검증 논문은 전무** → 자체 루프가 유일한 정직한 검증.

## 5. 개념 단위 구조 (concept-centric)
- **개념 레지스트리**: KB에 표준 개념명 + 별칭. 포스트→개념 매칭은 **결정론 정규화·별칭 매칭을 먼저**, 실패할 때만 LLM이 신규 개념 제안(신규·저신뢰 표시, 재등장해야 승격). → 새 판단 지점을 좁히고 감사 가능하게.
- **신호 로그(신설)**: `data/memory/signals.jsonl` — (개념ID, 날짜, 소스, 신호종류, 값) append-only 시간열. 랭킹·재라벨의 재료.
- **교과서 ↔ 개념 결합**: 교과서는 이제 **개념 하나에 붙는 살아있는 문서**. 강한 새 근거가 오면 갱신·추가(포스트마다 새로 찍지 않음).

## 6. 신뢰 설계 (요약)
- 불완전한 LLM을 **근거·검증·겸손·추적**으로 감싼다.
- LLM 판단 지점(Triage·Reader·Author·개념 제안)은 최소화하고, 검증(Fact-Check·랭킹·가짜필터)은 **결정론**으로 둔다.
- **자기진화 설계 에이전트 ❌**: 보상 해킹·외부검증 없는 국소최적 수렴 위험(Self-Evolving 안전성 문헌) → 대신 **"논문 워치"**(관련 문헌을 사람에게 *제안만*).
- **총괄 오케스트레이터 ❌**: 파이프라인이 고정 순서라 결정론 Loop면 충분(Anthropic, Building Effective Agents). 분야 확장 시 재검토.

## 7. 정직한 한계
- 전부 **상관이지 인과 아님**. "조기 신호 → 지속"은 우리 재라벨 루프로만 검증 가능.
- **Stack Overflow·유튜브 조회수**는 근거 약함 → 보조·상한 처리.
- **다운로드·SNS(인스타·X)**는 API 잠김/유료 → 목표엔 넣되 나중.
- "허브 소수만 추적"은 정치 도메인 결과(Gerard 2025) → 가설로만.

## 8. 범위 — v1(지금) vs 목표
- **v1 (좁게 시작)**: 기존 소스(HN·GeekNews) + **GitHub 채택 신호**(스타·이슈·PR·포크 증가율) + 개념 단위 저장 + 주목/채택 2시계열 + 잠정 라벨 + 신호 로그. **AI/LLM 한 분야에 집중.**
- **목표(딸림)**: 유튜브·뉴스 RSS·공식 SNS·다운로드·Q&A 확장, 분야 확대.
- 원칙: **작게 시작, 방향은 크게.** 초기 단계엔 넓게 벌리지 않는다.
